# Bounded priority check for the conditional height-domain result

Date: 2026-09-14. Verdict: VERIFIED restricted result within this lab;
mathematical novelty remains unconfirmed. No new global flatness bound.

The direct antecedent is Averkov–Codenotti–Macchia–Santos,
[A local maximizer for lattice width of 3-dimensional hollow bodies](https://arxiv.org/abs/1907.06199),
revised 2020, published 2021. Its contact programme, difference-body first
minimum inequality (Lemma 5.1, equation 14) and the rational-contact reduction
underlie the current work. McCormick's product envelopes and their multivariate
extensions are established methods; see the earlier detailed
[height-method priority audit](HEIGHT_EXCLUSION_LITERATURE.md).
The new local artifacts are particular checked height-domain exclusions and
conditional constants, not a new general convex-optimization principle.

A bounded fresh search used queries for "flatness constant" with "2026",
"hollow tetrahedra height flatness", and the bound "3.972", preferring arXiv
and primary mathematical papers. The first broad query returned substantial
irrelevant physics material, which was not used as evidence.
Primary abstracts inspected include:

- Beck–Everett, [Lonely Runner Relations](https://arxiv.org/abs/2609.06259),
  submitted 5 September 2026. The abstract uses the flatness constant to
  restrict potential lonely-runner counterexamples to finitely many
  hyperplanes; it does not state the determinant-five height-domain bounds.
- Averkov–Codenotti–Freyer–Huang,
  [Exact Flatness Constant for One-Point Convex Bodies and the Discrete
  Isominwidth Problem: The Planar Case](https://arxiv.org/abs/2604.27260),
  submitted 29 April 2026. The abstract establishes the planar one-interior-point
  constant 3, which is a different problem from the hollow 3D class here.
