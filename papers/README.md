# Primary sources

Third-party papers and extracted full texts are not redistributed. All exact
replays run without downloading these documents.

- Codenotti–Santos, *Hollow polytopes of large width*: [arXiv:1812.00916](https://arxiv.org/abs/1812.00916).
- Averkov–Codenotti–Macchia–Santos, *A local maximizer for lattice width of 3-dimensional hollow bodies*: [arXiv:1907.06199](https://arxiv.org/abs/1907.06199), [journal DOI](https://doi.org/10.1016/j.dam.2021.04.009).
- Hurkens, *Blowing up convex sets in the plane*: [DOI](https://doi.org/10.1016/0024-3795(90)90010-A).
- Averkov–Wagner, *Inequalities for the lattice width of lattice-free convex sets in the plane*: [arXiv:1003.4365](https://arxiv.org/abs/1003.4365).
- Averkov–Codenotti–Freyer–Huang, *Exact Flatness Constant for One-Point Convex Bodies and the Discrete Isominwidth Problem: The Planar Case*: [arXiv:2604.27260](https://arxiv.org/abs/2604.27260).
