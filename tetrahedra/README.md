# Tetrahedral models

src/examples.py reconstructs Delta from its original affine lattice basis.
proofs/BASELINE_RECONSTRUCTION.md documents the derivation.
experiments/discovery.py uses a general eight-parameter barycentric contact
matrix with zero diagonal and positive off-diagonal entries summing to one
in each column. No cyclic or metric symmetry is imposed.

This chart fixes the unimodular contact tetrahedron. It is incomplete for
other contact determinants, and determinant-one contact equivalence does not
make all surrounding bodies geometrically equivalent.
